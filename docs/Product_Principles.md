# Product Principles

1. El proyecto es el centro.
2. Una pantalla responde una pregunta.
3. La respuesta principal debe entenderse en tres segundos.
4. Menos datos, más decisiones.
5. El tono es sobrio, preciso y tranquilo.
6. El Índice DOCH20 debe ser transparente.
7. Sin feed, likes, rankings ni comparación social en el MVP.
